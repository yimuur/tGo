# 增量迁移目录

## 命名规范

- 文件命名：`NNNN_描述.sql`（NNNN 为 4 位递增版本号，如 `0001`、`0002`）；
- 按 NNNN 升序执行，启动时自动应用**未应用**的迁移（记录于 `schema_migrations` 表）；
- 迁移必须**向后兼容**（新增列带默认值；删除/重命名列需两步迁移，见 DATABASE §4）；
- 迁移脚本应尽量幂等（`IF NOT EXISTS` / `IF EXISTS`），保证可重跑安全。

## 基线说明

基线 DDL 位于 [schema.sql](../schema.sql)（非本目录），本目录仅存放**增量**变更。
